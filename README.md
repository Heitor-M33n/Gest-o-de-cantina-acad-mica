# Gestão de Cantina Acadêmica

Sistema desenvolvido como projeto acadêmico para a disciplina de Projeto de Desenvolvimento de Software (PDS), com o intuito de criar uma solução para auxiliar no gerenciamento de uma cantina, facilitando o controle de produtos, vendas, usuários e estoque.

## Sobre o projeto

A Gestão de Cantina Acadêmica é uma aplicação desenvolvida para melhorar a organização e eficiência dos processos de uma cantina dentro de uma instituição de ensino.
O sistema visa tornar mais simples o controle das atividades que ocorrem dia a dia, possibilitando a gestão dos produtos disponíveis, o monitoramento das vendas, o controle do estoque e a administração dos diversos tipos de usuários que fazem parte do funcionamento da cantina.

## Objetivos

- Coordenar a gestão dos produtos da cantina
- Tornar mais simples o gerenciamento de vendas e pedidos
- Ajudar a monitorar o estoque
- Otimizar a gestão das informações da cantina
- Oferecer uma experiência mais eficaz tanto para os usuários quanto para os funcionários

## Perfis de usuários

O sistema possui diferentes níveis de acesso, cada um com responsabilidades específicas dentro da gestão da cantina acadêmica:

### Administrador

Responsável pelo gerenciamento geral do sistema, incluindo o cadastro e controle de usuários, gerenciamento de acessos e manutenção das configurações da aplicação.

### Gestor

Responsável pela administração da cantina, realizando o controle de estoque, atualização de preços e produtos, cadastro de novos itens, acompanhamento de vendas, recebimento de alertas de estoque baixo e consulta de relatórios e movimentações.

### Vendedor

Responsável pelo registro das vendas realizadas no sistema, garantindo que os produtos vendidos sejam contabilizados e que o estoque seja atualizado automaticamente.

### Usuário

Responsável por consultar informações disponíveis no sistema, como produtos e disponibilidade em estoque, além de realizar interações conforme as permissões definidas.

## Funcionalidades

- Cadastro e gerenciamento de produtos
- Controle de estoque
- Registro e acompanhamento de vendas
- Gerenciamento de usuários
- Controle de permissões de acesso
- Organização das informações da cantina
- Geração de relatórios de movimentação
